# Hangman Game

## Description
A simple text-based Hangman game developed using Python.

The player has to guess a hidden word one letter at a time.

## Features
- Uses 5 predefined words
- Random word selection
- Maximum 6 incorrect guesses
- Checks repeated guesses
- Simple console input/output

## Technologies Used
- Python
- Random module
- While loop
- If-else
- Strings
- Lists

## How to Run
1. Open `hangman.py` in VS Code.
2. Run the Python file.
3. Enter one letter at a time.
4. Try to guess the hidden word before 6 wrong guesses.
